What is JavaScript?

JavaScript is the programming language of the web. HTML gives a page its structure, CSS gives it style, and JavaScript gives it behaviour: reacting to clicks, changing content, fetching data and more.

The examples below use console.log(), which prints a value. Normally that appears in the browser's DevTools console (press F12), but on this page each example is actually run and its output is shown in the green box under the code.

1. Variables

Variables store values. Use let for values that change and const for values that don't. The older var still works but is best avoided in modern code.

Code
let age = 20;
const name = "Yahia";

console.log(name);
console.log(age);

age = 21; // allowed: let can be reassigned
console.log(age);
Code
const pi = 3.14;
pi = 3; // error: const cannot be reassigned

2. Data Types

JavaScript has a few primitive types: string, number, boolean, undefined, null (plus bigint and symbol). Everything else, like arrays and functions, is an object. The typeof operator tells you a value's type.

Code
console.log(typeof "hello");
console.log(typeof 42);
console.log(typeof 3.5);
console.log(typeof true);
console.log(typeof undefined);
console.log(typeof null);      // a famous quirk of the language
console.log(typeof [1, 2, 3]);
console.log(typeof { a: 1 });
console.log(typeof function () {});

3. Operators

Arithmetic, comparison and logical operators. Prefer strict equality ===, which also compares types, over loose ==, which converts types first.

Code
console.log(10 + 3);   // addition
console.log(10 - 3);   // subtraction
console.log(10 * 3);   // multiplication
console.log(10 / 3);   // division
console.log(10 % 3);   // remainder
console.log(2 ** 3);   // exponent
Code
console.log(5 == "5");   // loose: converts "5" to 5
console.log(5 === "5");  // strict: different types
console.log(5 !== 3);
console.log(7 > 3 && 2 > 9);  // AND: both must be true
console.log(7 > 3 || 2 > 9);  // OR: at least one true
console.log(!true);             // NOT

4. Strings

Strings can use single quotes, double quotes, or backticks. Backticks create template literals, which let you insert values with ${...}.

Code
const first = "Ada";
const last = "Lovelace";

console.log(first + " " + last);          // concatenation
console.log(`Hello, ${first} ${last}!`);  // template literal
console.log(first.length);
console.log(last.toUpperCase());
console.log(last.includes("love"));     // case-sensitive!
console.log(last.slice(0, 4));
console.log("a,b,c".split(","));

5. Conditionals

if / else if / else runs code depending on a condition. The ternary operator condition ? a : b is a short form, and switch compares one value against many cases.

Code
const score = 76;

if (score >= 90) {
  console.log("Grade: A");
} else if (score >= 75) {
  console.log("Grade: B");
} else {
  console.log("Grade: C");
}

const status = score >= 50 ? "Pass" : "Fail";
console.log(status);
Code
const day = "Sat";

switch (day) {
  case "Sat":
  case "Sun":
    console.log("Weekend!");
    break;
  default:
    console.log("Weekday");
}

6. Loops

Loops repeat code. The most common are for, while, and for...of (for arrays).

Code
for (let i = 1; i <= 3; i++) {
  console.log("for loop, i =", i);
}

let count = 3;
while (count > 0) {
  console.log("while countdown:", count);
  count--;
}

const fruits = ["apple", "banana", "cherry"];
for (const fruit of fruits) {
  console.log("fruit:", fruit);
}

7. Functions

Functions are reusable blocks of code. They take parameters and can return a value. Arrow functions are a shorter syntax.

Code
// function declaration
function add(a, b) {
  return a + b;
}

// arrow function
const square = (n) => n * n;

// default parameter
function greet(name = "stranger") {
  return `Hi, ${name}!`;
}

console.log(add(4, 6));
console.log(square(7));
console.log(greet("Yahia"));
console.log(greet());

8. Arrays

Arrays are ordered lists. Indexes start at 0. Methods like map, filter and reduce transform arrays without writing loops by hand.

Code
const nums = [5, 2, 8, 1];

console.log(nums[0]);       // first item
console.log(nums.length);

nums.push(10);              // add to end
console.log(nums);

nums.pop();                 // remove from end
console.log(nums);

console.log(nums.indexOf(8));
Code
const numbers = [1, 2, 3, 4, 5, 6];

const doubled = numbers.map((n) => n * 2);
const evens = numbers.filter((n) => n % 2 === 0);
const total = numbers.reduce((sum, n) => sum + n, 0);

console.log(doubled);
console.log(evens);
console.log(total);

9. Objects

Objects group related data as key: value pairs. Values can be anything, including functions (called methods).

Code
const student = {
  name: "Yahia",
  age: 20,
  courses: ["Web", "Math"],
  introduce() {
    return `I'm ${this.name}, ${this.age} years old.`;
  },
};

console.log(student.name);        // dot notation
console.log(student["age"]);      // bracket notation
console.log(student.courses[1]);
console.log(student.introduce());

student.age = 21;                 // update
student.city = "Cairo";           // add new key
console.log(Object.keys(student));
Code
// destructuring pulls values out into variables
const { name, age } = student;
console.log(name, age);

const [firstCourse] = student.courses;
console.log(firstCourse);

10. The DOM

The DOM (Document Object Model) is how JavaScript sees and changes the HTML page. You select elements, change their content or style, and listen for events.

Code
<p id="message">Click the button</p>
<button id="btn">Click me</button>

<script>
  const message = document.getElementById("message");
  const btn = document.getElementById("btn");
  let clicks = 0;

  btn.addEventListener("click", () => {
    clicks++;
    message.textContent = `Clicked ${clicks} time(s)`;
    message.style.color = "crimson";
  });
</script>
